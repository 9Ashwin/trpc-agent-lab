Overview

This skill runs small Python scripts in the workspace to compute values
the built-in calculator tool does not cover.

Examples

1) Print the first 20 Fibonacci numbers

   Command:

   python3 scripts/fib.py 20

Output

- The sequence is printed to stdout.
